# Two-minute clickable walkthrough

Use synthetic data and start with **Change building**. This is a navigation script for the prototype, not an instruction to submit or publish anything. Select **Maple Court Apartments** for the walkthrough.

| Time      | Click                                                                                                                         | Show                                                                                                                                                                                    |
| --------- | ----------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00–0:15 | **Maple Court Apartments** → **Confirm figures**                                                                              | $112.50 water charge, $3.95 separate fee; the sample is reviewed before calculation.                                                                                                    |
| 0:15–0:30 | **I don’t have it** → **Continue to neighbours**                                                                              | Formula Detective says it needs four households.                                                                                                                                        |
| 0:30–0:50 | Consent → **Add demo neighbours** → **Run building check**                                                                    | Six synthetic contributions; no neighbour row is shown.                                                                                                                                 |
| 0:50–1:15 | Show result and Formula Detective                                                                                             | Likely rule: $0.05 per sq ft + $22.50 per occupant; five of six match. The viewer is $22.50 above the pattern.                                                                          |
| 1:15–1:30 | Vacancy card → **Try shifted scenario**                                                                                       | Observed sample is consistent with landlord absorption. The what-if shows $2,304 pool, 6.25% vacant share, $135 vacant share of the eligible pool and $6 modeled impact for the viewer. |
| 1:30–1:50 | **Open report** → **Continue to demo checkout** → enter `DEMO100` → **Apply** → **Complete demo order** → **Building letter** | Proposed $4.99 one-time price, $0 demo total, no real charge. Anonymous request from six sample households.                                                                             |
| 1:50–2:00 | **Copy verification bundle** → **Verify code**                                                                                | Pasted snapshot matches its report code; it is a consistency check, not document authentication.                                                                                        |

Optional after the timed run: show **Why did my bill change?** in the room. November is a modeled example based on the viewer's October inputs; the four parts add to the total to the cent. Change the viewer's October charge by one cent, rerun, and show a different report code.

To show the other state, choose **Change building → My building is not listed**. The screen shows no neighbour comparison or alert signup because no shared data or notification backend exists. It does offer an independent check using the renter's own documents. Birch and Cedar produce different flagged neighbour examples; Riverstone produces a consistent one.

For a real-input path that needs no neighbours, choose **My building is not listed → Check with my own documents**. Click **Check this charge** with missing values to see an evidence checklist and downloadable records request. Then use **Load complete sample → Check this charge** for a live $90.00 expected charge and $22.50 difference, with a separate clarification request. Edit the charge to $90.00 and rerun to see the finding change. The three sample documents are linked beside the load button.

To show the moving use case, choose **Moving → Maple Court Apartments**. Three monthly summaries come from separate synthetic statement cohorts. Save the building, refresh, then use **View history** to demonstrate the browser-local return mechanic. Remove the saved building in that view.

To test upload, [download the Maple Court statement PDF](https://sharecheck-business-cup-2026.loosephlox32.chatgpt.site/samples/maple-court-statement.pdf), select Maple Court, choose the file on the Statement screen, and review the extracted $112.50 charge, $3.95 fee, 900 sq ft, two occupants, and two bedrooms.

For a real pilot, cross-device rooms and private submissions require backend identity, authorization, storage, and server-side aggregation. A real extraction service would need private server credentials; the current PDF extraction stays in the browser.
